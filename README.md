# DealZone - Affiliate Marketing Website

Modern affiliate marketing website jahan aap products promote kar sakte ho aur naye products launch kar sakte ho.

## Live Preview

GitHub Pages se enable karke live dekh sakte ho:
`https://01palhemant-boop.github.io/my-website/`

## Features

- Clean & modern responsive design
- Featured products section with sample products
- Category browsing
- **Launch Product form** – form se naya product add kar sakte ho (browser mein temporary)
- Mobile-friendly navigation
- Ready for real affiliate links

## How to use

1. `index.html` open karo browser mein
2. Products section mein sample products dikhenge
3. "Launch Product" section mein form bhar ke naya product add kar sakte ho
4. Har product card pe **Buy Now / Affiliate Link** button hai – wahan apna real affiliate link daal do

## Structure

```
my-website/
```
